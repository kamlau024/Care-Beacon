# core biopsy

## Description

A type of needle biopsy in which a large, hollow cutting needle or probe is used to remove a cylinder-shaped sample (core) from a tumour or abnormal mass to examine it under a microscope.

Also called core needle biopsy when a cutting needle is used to remove the tissue.
