# nucleus

## Description

The part of the cell that holds the chromosomes, which contain DNA( genetic information).

The plural of nucleus is nuclei.

* * *

**DNA:**

The molecules inside the cell that program genetic information. DNA determines the structure, function and behaviour of a cell.
