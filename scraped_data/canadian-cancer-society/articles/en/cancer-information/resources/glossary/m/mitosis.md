# mitosis

## Description

The process by which a cell divides to form 2 new cells. Each new cell receives a complete set of chromosomes from the original cell.

* * *

**chromosomes:**

The part of a cell that contains DNA ( genetic information).

In humans, each cell contains 23 pairs of chromosomes or 46 chromosomes in total.
