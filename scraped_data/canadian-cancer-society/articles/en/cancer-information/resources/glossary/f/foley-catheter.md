# Foley catheter

## Description

A catheter (flexible tube) that is passed through urethra into the bladder to drain urine from the body.

A Foley catheter is a type of indwelling catheter.

* * *

**indwelling catheter:**

A type of catheter (flexible tube) that is left in place inside the body for a period of time.

For example, a Foley catheter is a type of an indwelling catheter.
